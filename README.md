# YFD Esports — YFD Days Season 4

React + TypeScript frontend for the YFD Days esports tournament site, implemented from the Stitch project **Remix of YFD Esports Tournament Landing Page**.

## Pages

| Route       | Page                    |
| ----------- | ----------------------- |
| `/`         | Landing                 |
| `/register` | Tournament registration |
| `/news`     | News & announcements    |
| `/rules`    | Rules & FAQ             |

## Stack

- Vite + React 19 + TypeScript
- React Router
- Tailwind CSS v4
- Demo data in `src/data/demo.ts` (swap for API later)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
